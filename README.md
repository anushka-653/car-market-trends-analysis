# Car Market Trends Analysis with Car Dekho Data

## Project Description
This project analyzes Car Dekho vehicle data to identify pricing patterns
and factors affecting resale value.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git & GitHub

## Analysis Performed
- Data Cleaning
- Exploratory Data Analysis
- Selling Price Analysis
- Car Age Analysis
- Mileage Analysis
- Fuel Type Analysis
- Correlation Analysis

## Key Findings
- Present Price has a strong positive relationship with Selling Price.
- Vehicle age has a negative relationship with resale value.
- Diesel vehicles show higher average resale values in the dataset.
- KMs Driven has a relatively weak direct relationship with Selling Price.
